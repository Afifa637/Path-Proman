# Bangla suffix list — PLAN.md task T6b.
#
# Hand-authored (Tier A).  Two consumers, which is why it is a resource rather
# than a constant buried in a function:
#   1. the rule-based stemmer behind tier-3 stem+synonym F1 (T4 / §9);
#   2. Tier B's MorphSpan-MLM, which masks a whole stem-run or a whole
#      suffix-chain and cannot be implemented without a stem/suffix boundary
#      (PLAN.md §8 X2/X5).  This is why T6b runs on D0, before X2.
#
# Ordered longest-first; the stemmer strips the longest match.  Comments and
# blank lines are ignored.  Verb morphology is deliberately NOT here: Bangla
# verb inflection is irregular enough that a rule list does more harm than good
# for lexical matching, and the char n-gram vectoriser (T5) absorbs it anyway.
